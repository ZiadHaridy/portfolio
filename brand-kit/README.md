## Print files for clothing (`print/`)

| Garment / method | File |
| --- | --- |
| Light fabric (white, grey, sand): DTG / DTF | `za-print-color-6000.png` |
| Dark fabric (black, navy): DTG / DTF | `za-print-white-6000.png` |
| One-colour screen print, embroidery, vinyl | `za-mark-mono-black.pdf` / `.svg`, `za-mark-mono-white.svg` |
| Two-colour screen print | `za-mark-color.pdf` (vector) |
| Name lockup (back print, tote bags) | `za-print-lockup-color-6000.png`, `za-print-lockup-white-6000.png`, or `za-lockup*.svg` |

PNGs are 6000 px wide with transparent backgrounds, enough for about 50 cm wide at 300 dpi. PDFs and SVGs are vector, so they scale to any size. Send printers the vector file whenever they accept it.

### Suggested sizes

- Chest logo: 8–10 cm wide
- Back print: 25–30 cm wide
- Sleeve / collar: 5–6 cm wide
- Embroidery: at least 7 cm wide, so the thin slits stay at least 2 mm (each slit is about 2.8% of the mark's width)
